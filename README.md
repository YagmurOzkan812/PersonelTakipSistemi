# Personel Takip Sistemi

Bu proje, şirketlerin personel yönetim süreçlerini dijitalleştirmek ve kolaylaştırmak amacıyla geliştirilmiş kapsamlı bir **Personel Takip Sistemi**dir. C# Programlama dili ve Windows Forms teknolojisi kullanılarak hazırlanmıştır.

## 📺 Proje Tanıtım Videosu

Projenin detaylı anlatımı ve kullanımını aşağıdaki YouTube linkinden izleyebilirsiniz:

[**👉 Proje Tanıtımı (YouTube)**](https://youtu.be/jiRu_xhHCBI)

## 🚀 Özellikler

Proje aşağıdaki temel modülleri içermektedir:

- **Personel İşlemleri**: Personel ekleme, düzenleme, silme ve listeleme.
- **Maaş Yönetimi**: Maaş bilgilerini görüntüleme ve yönetme.
- **İzin Takibi**: Çalışan izinlerinin takibi ve yönetimi.
- **Performans Yönetimi**: Çalışan performans değerlendirmeleri.
- **Kullanıcı Girişi**: Güvenli giriş sistemi.

## 🛠️ Kullanılan Teknolojiler

- **Yazılım Dili**: C#
- **Arayüz**: Windows Forms (WinForms)
- **Veritabanı**: Microsoft SQL Server
- **IDE**: Visual Studio

## ⚙️ Kurulum ve Çalıştırma

Projeyi yerel makinenizde çalıştırmak için aşağıdaki adımları izleyin:

1.  **Veritabanı Kurulumu**:
    - Proje klasöründe bulunan `26_132430040.sql` dosyasını SQL Server Management Studio (SSMS) üzerinde açın ve çalıştırarak veritabanını oluşturun.
    - Bağlantı cümleciğini (Connection String) `personelTakip.DAL` veya `App.config` dosyasında kendi sunucu ayarlarınıza göre güncelleyin (gerekirse).

2.  **Projeyi Açma**:
    - Visual Studio'yu açın.
    - `PersonelTakipSistemi.sln` dosyasını seçerek projeyi yükleyin.

3.  **Çalıştırma**:
    - Projeyi derleyin ve `Start` tuşuna basarak uygulamayı başlatın.
